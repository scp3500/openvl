OpenVL

给没有视觉能力的 AI 模型装上眼睛

$ openvl -c "这张图是什么"
正在分析图片...

三步搞定

1
安装
npm install -g @scp3500/openvl
2
配置
openvl setup
3
截图提问
openvl -c "图中是什么"

支持的命令

$ openvl D:\截图.png # 直接看文件
$ openvl -c # 读剪贴板截图
$ openvl -c "这张图里有什么" # 截图 + 提问
$ openvl a.png b.png # 多张图一起传
$ openvl doctor # 环境诊断
$ openvl setup # 交互式配置
