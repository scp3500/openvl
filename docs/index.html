OpenVL

让没有视觉能力的 AI 模型也能看懂图片。截图、提问、得到答案。

$ npm install -g @scp3500/openvl # 安装
$ openvl -c "这张图里有什么" # 截图提问
$ openvl -c "这张截图是什么"

命令参考

openvl <路径>
直接看文件
openvl -c
读剪贴板截图
openvl -c "提问"
截图 + 提问
openvl --stdin
管道传 data URI
openvl --base64
传 base64 数据
openvl a.png b.png
多张图一起传
openvl -s 512
图片尺寸
openvl -T high
思考深度
openvl -t 0.3
温度控制
openvl doctor
环境诊断
openvl setup
交互式配置
openvl -cfg
查看配置
