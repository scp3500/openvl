OpenVL

给没有视觉能力的 AI 模型装上眼睛

这是什么？

OpenVL 是一个命令行工具，让 DeepSeek、OpenCode、Claude Code 等非视觉模型也能看懂图片。

🖼️ 用户发图片 → OpenVL 调多模态 API → 📝 返回文字描述 → 🤖 AI 根据描述回复

快速安装

# 安装
npm install -g @scp3500/openvl

# 配置 API
openvl setup

# 截图提问
openvl -c "这张图里有什么"
GitHub npm

支持的命令

命令说明
openvl <路径>直接看文件
openvl -c读剪贴板截图
openvl -c "提问"截图 + 提问
openvl --stdin从管道读 data URI
openvl --base64 ...传 base64 数据
openvl a.png b.png多张图一起传
openvl doctor环境诊断
openvl setup交互式配置
